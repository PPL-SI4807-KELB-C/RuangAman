# Petunjuk untuk AI Agent

Sebelum membuat branch, commit, atau PR di repo ini, baca [docs/panduan-commit-jira.md](docs/panduan-commit-jira.md). Ringkasnya:

- Issue key Jira berformat `PKBC-<angka>` wajib ada di nama branch, pesan commit, dan judul PR. Daftar key ada di panduan itu.
- Pakai identitas Git milik manusia yang meminta pekerjaan; jangan menambahkan `Co-Authored-By` atau penanda agent.
- PR ke `develop`; `main` dilindungi. Jalankan `php artisan test` sebelum push.
